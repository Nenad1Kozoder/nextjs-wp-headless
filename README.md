# Next.js + WordPress Headless CMS

Boilerplate za Next.js (JavaScript, module.scss) sa WordPress-om kao headless CMS koristeći:

- WPGraphQL
- Polylang (višejezičnost)
- Next.js 14 (SSG + ISR)

## Quick start

```bash
# 1. Kloniraj
git clone https://github.com/YOUR_USERNAME/nextjs-wp-headless.git
cd nextjs-wp-headless

# 2. Instaliraj zavisnosti
npm install

# 3. Kopiraj env i popuni
cp .env.local.example .env.local

# 4. Pokreni dev
npm run dev
```
